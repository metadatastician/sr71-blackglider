# Architecture — SR-71 BlackGlider

The architecture is generated by one direction of authority: **Conway may
produce geometry; geometry may not produce Conway.**

```text
preflight choices
       │ construct once
       ▼
┌───────────────────────────────────────────────────────────┐
│ G₀: complete initial B3/S23 pattern                       │
└──────────────────────────┬────────────────────────────────┘
                           │ only World::evolved()
                           ▼
┌───────────────────────────────────────────────────────────┐
│ canonical Life history Gₜ                                │
│ fixed Moore neighbourhood · synchronous B3/S23 · dead rim │
└───────────────┬───────────────────────┬───────────────────┘
                │ immutable borrow      │ independent replay
                ▼                       ▼
       pattern/worldline         no-launch counterfactual
           detection Sₜ                 Sₜ
                │                       │
                └──────────┬────────────┘
                           ▼
                causal difference Gₜ XOR Sₜ
                           │ analysis only
                           ▼
┌───────────────────────────────────────────────────────────┐
│ spacetime embedding Φₜ(x,y)                              │
│ rotated chart · curved surface · local flight frame       │
└──────────────────────────┬────────────────────────────────┘
                           ▼
               meshes · textures · camera · sound
```

There is intentionally no return arrow.

## Physical layer

[`src/life.rs`](src/life.rs) owns the canonical state. Its cell buffer is
private. `World::from_cells` constructs generation zero; after construction,
`World::evolved` is the sole public physical transition. It returns a new world
computed synchronously from the previous one.

The current reference world is finite with permanently dead exterior cells.
That boundary is part of the implemented mathematics. A mission may claim
equivalence with the infinite plane only for a measured interval whose causal
activity remains clear of the rim.

`World::canonical_bytes` gives this finite state a stable, exact encoding.
Replay and reaction certificates contain complete initial worlds and expected
results, rather than trusting a screenshot, detector label or renderer output.

There is no authoritative player anchor or heading. [`src/glider.rs`](src/glider.rs)
detects glider phase and orientation from an immutable world. Deleting the
detector would blind the camera but could not alter a cell.

## Counterfactual layer

The counterfactual is another complete, valid B3/S23 history. It begins with the
same world except for the launch signal. The analytical difference

\[
D_t=G_t\oplus S_t
\]

is never evolved as a Life pattern and never written into the canonical world.
It attributes causal descendants without tagging cells or granting the player
special survival rules.

## Geometric layer

[`src/embedding.rs`](src/embedding.rs) accepts `&World`, an immutable borrow. It
maps canonical cell events into three-dimensional positions. Its initial chart
is

\[
X=(x+y)/2,\qquad Y=(x-y)/2.
\]

The code retains doubled integer coordinates `u=x+y`, `v=x-y` until display.
The inverse is admitted only when `u` and `v` have the same parity. The curved
surface is a height graph over those exact coordinates and is followed by a
rigid bank/pitch transform: this avoids surface folding or event identification
in the present proof-oriented embedding. Displayed distance, slope and
intersection are never returned to the kernel and never determine Moore
adjacency.

## Turns

An apparent turn is a change in the embedding or camera. Every object transforms
consistently, so canonical encounters remain the same.

An objective turn is a detected change in a causal glider signal relative to
the raw lattice. The foundation seeds a stable Snark and an incoming glider in
`G₀`; repeated `World::evolved` calls produce the outgoing heading. No turn API
exists.

The future renderer may derive a smooth bank and control-surface animation from
the incoming and outgoing detected worldlines. The causal order must remain:

```text
B3/S23 reaction → detected turn → local curvature/bank → pixels
```

## Inputs

Post-launch input may change camera, frame, pause state, display speed and
analysis. For a fixed canonical generation number it must not change `Gₜ`.

Physical choices belong to initial-condition construction or to control signals
already encoded in that condition. A live keypress that creates, removes,
rotates or relocates cells would define a driven automaton, not an autonomous
Conway history, and is outside the contract.

## Relationship to F19 and F117A

F19 made the substrate load-bearing and introduced counterfactual trace.
F117A proved that a richer 3D camera and radar interpretation could remain
downstream of a 2D Life world. Both kept a pre-contact kinematic player layer.

SR-71 retains the intellectual gains but removes that seam. The counterfactual
now measures two complete worlds; it does not license an absent player overlay.
The renderer still observes, but the player signal also lives in the sole
canonical grid from generation zero. This is the architectural step change.

## Verification boundary

The Rust suites provide exhaustive finite checks where the domain is small and
bounded traces where it is not. The Idris2 constitutional companion proves a
small, implementation-independent model without unsafe proof escapes. There is
currently no theorem connecting every Rust `World::evolved` execution to that
model, no verified compiler chain, and no universal Snark lane theorem. Those
are explicit engineering and verification frontiers, not assumed consequences
of the architecture.
