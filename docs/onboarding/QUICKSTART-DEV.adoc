= sr71-blackglider — Quick Start for Developers
:toc:
:toclevels: 2

== Tech Stack

* *Rust 1.97* (pinned in `mise.toml`) — the B3/S23 reference kernel, glider
  catalogue, spacetime embedding, and certificates (`src/`), with the
  exhaustive C1–C13 test suite (`tests/`). The crate is
  `#![forbid(unsafe_code)]`.
* *Idris2 0.7.0* — the gated constitutional proof companion
  (`verification/proofs/idris2/`, MANIFEST-driven).
* *Zig* — FFI/ABI seam scaffold (`src/interface/ffi/`), builds but not yet
  wired into the golden path.
* *just 1.56* — task runner (`Justfile`).

== Set Up Development Environment

=== Option A: Guix (preferred)

[source,bash]
----
guix shell -D -f build/guix.scm
----

=== Option B: mise

[source,bash]
----
git clone https://github.com/metadatastician/sr71-blackglider.git
cd sr71-blackglider
mise install    # installs the pinned rust + just
----

== Contractile Invariants

Read `.machine_readable/contractiles/must/Mustfile.a2ml` before making
changes. Key invariants that must never be violated:

* *One canonical B3/S23 world is the whole physical truth.* Presentation
  (surfaces, textures, curvature) is a one-way observer: it may render
  Conway's history, never author it.
* *Objective manoeuvres are Conway reactions*, not commanded kinematics.
* *No `unsafe` Rust* (`#![forbid(unsafe_code)]`), no `believe_me` /
  `assert_total` in gated proofs.
* *The quarantine ledger is honest*: a quarantined proof module that starts
  compiling is itself a gate failure — update the MANIFEST, don't ignore it.
