== What this is, and how it works

*What it is.* A short, dated snapshot of what metadatastician can honestly and
verifiably claim about *SR-71 BlackGlider* at one exact commit. Nothing here is
marketing and nothing is a promise about the future — those live in the README.
This file is the receipt.

*How it stays trustworthy.* Three moving parts:

. *Ground truth, not memory.* Every claim below was produced by _running the
  project's own checks_ in the session that wrote this file. Where a status doc,
  the `Justfile`, or memory said otherwise, the live run won and the
  contradiction is flagged — several are, in <<not-claimed>>.
. *A frozen anchor.* The file names the exact commit, branch, UTC timestamp and
  toolchain (see <<verifiable-anchor>>), so "true" always means "true _at this
  point_". Move the SHA and this file is a draft until it is re-run.
. *A real signature.* It is landed by a *signed git commit*; that signature over
  this content at the anchored SHA is what makes the affirmation tamper-evident
  and attributable — not the prose alone.

*We are fallible.* This is our best honest belief, not a proof of its own
correctness. Treat it as a falsifiable claim, not gospel.

== The epistemic contract (read this before you trust _or_ attack)

This document records metadatastician's *best belief* at the timestamp above. It
is *not a guarantee of correctness.* The only guarantee is *no intentional
overclaim*: where something is proven we say "proven"; where it is a documented
trust boundary, an experiment, or an unwired module, we say so; where a claim is
the README's aspiration rather than a checked result, we say so. An honest claim
that later turns out false is an *error to be fixed* — not a lie.

*Standing invitation to refute.* You are invited to bulldoze any claim in this
file. Bring a counter-example, a failing run, or a contradicting source.

This session did exactly that to itself: an adversarial review of the proof
repair found *two defects introduced by the repair* — see
<<caught-by-refutation>>. Both are recorded rather than quietly fixed, because
the failure mode this project most needs to keep visible is a repair that
weakens the thing it repairs.

[#caught-by-refutation]
== What refutation caught in this very session

Recorded because an affirmation that only lists successes is advertising.

. *A repair that weakened a proof.* Restating `FieldAligned` as divisibility
  without a `NonZero` conjunct admitted `alignment = 0`, and a complete
  `CABICompliant` certificate could be built for a size-0/alignment-0 struct
  that cannot exist in C. The phrasing it replaced could not even be _formed_ at
  alignment 0 — uninhabitable, therefore stronger. A doc comment asserted the
  exact opposite. *Fixed*: `NonZero` conjunct added; the attack is now rejected
  (`Mismatch between: S ?x and 0`) while legal layouts still prove.
. *A repair that cost the representation.* De-erasing proof witnesses
  (quantity `0` → unrestricted) made `SafePtr` stop being newtype-transparent —
  measured with `idris2 --codegen refc --dumpcases`, it became a two-field heap
  object per pointer. *Fixed*: reverted; the correct repair was one character on
  the *accessor* (`0 safePtrNeverNull`), which is what the shipped seam
  `src/interface/Abi/Types.idr` already does.

[#not-claimed]
== What we do NOT claim

Silence is not affirmation. These are named because they are *not* verified.

* *The Coq, Agda and Lean modules prove nothing about this project.* They are
  verbatim RSR template exemplars — a toy `TyNat`/`TyBool` type system, list
  append length preservation, a `Result` functor. They compile and they are
  gated. Their green is a statement about the *gate*, not about Conway physics.
  (Debt P-1.)
* *No refinement connects the Idris2 model to the Rust kernel.* The constitution
  is proved; the kernel is exhaustively tested; *nothing proves the two agree*.
  A divergence would leave both ledgers green. (Debt P-2.)
* *The Idris2 ABI modules prove properties of a model of a C ABI, not of the
  shipped FFI.* `grep` finds no `CABICompliant`/`StructLayout` reference outside
  `verification/proofs`; the only inhabitant is a fieldless empty struct. Do not
  read them as "the C ABI is proven compliant". (Debt P-3.)
* *Exhaustion is over finite domains.* 512/512 rules and 65,536/65,536 4×4
  worlds are complete _for those domains_. Nothing establishes behaviour on
  larger worlds beyond the 240-generation Snark trace. (Debt T-1.)
* *`verification/proofs/tlaplus/StateMachine.tla` is checked by nothing* and
  models a generic request pipeline unrelated to this project. (Debt P-4.)
* *The renderer and the mission semantics do not exist.* `STATE.a2ml` records
  25% complete. This is a proven foundation, not a game.
* *Nothing is required to merge.* `.github/settings.yml` sets `contexts: []` and
  probot/settings is not installed, so every gate is advisory. (Debt CI-2.)
* *The new `proof-gate.yml` has not yet had a green run.* Until 2026-08-07 no
  workflow ran any proof gate, the Zig tests, or `just test` — all of it was
  enforced on one laptop. The workflow that fixes this is itself unproven until
  it runs. (Debt CI-1, CI-3.)
* *`reuse lint` fails* — 224 of 453 tracked files carry copyright information,
  and an AGPL licence text ships in a repo that bans AGPL. (Debt L-1, L-2.)
* *The Zig FFI is an unconsumed seam.* It compiles and tests, but exposes no
  Conway concept and nothing in the kernel calls it. (Debt C-3.)
