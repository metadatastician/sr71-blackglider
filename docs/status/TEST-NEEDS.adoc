== Needs (priority order)

. *Wire or descope the Coq proof* — TypeSafety.v compiles but nothing runs
  it; either add a `check-proofs.sh coq` mode with its own MANIFEST or move
  it under an explicitly-unwired examples note. Unwired is not done.
. *Zig FFI test step* — `zig build test` target plus wiring into `just test`,
  or remove the scaffold until the FFI seam is actually consumed (this is
  also the READINESS E→D promotion blocker).
. *Fuzz harness* — a `cargo-fuzz` target over `Life::step` input worlds would
  exercise the kernel beyond the exhaustive finite domains (low priority:
  the 4×4 domain is already complete, so fuzzing adds value only at larger
  world sizes).
. *Mission-specification tests* — blocked on the frozen mission spec
  (PROOF-ROADMAP): once a mission exists, its replay certificates become
  golden-file tests.
