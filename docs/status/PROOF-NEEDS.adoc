= Proof Requirements — SR71_BLACKGLIDER

Reconciled 2026-08-07 against measured runs. The previous revision predated the
proof workup and listed every obligation as "Needed" — including several since
discharged, and one (TLA+) that no gate has ever checked. This file now records
what remains *open*, and states for each discharged obligation *by what means*
it was discharged, because those means are not equivalent.

== How to read a status in this file

Three tiers, and they must never be collapsed into one word "proven":

[cols="1,3,4", options="header"]
|===
| Tier | Means | What it entitles you to say

| *T-EXH* | Discharged *by exhaustion over a stated finite domain* — a Rust test that enumerates the whole domain. | "Holds for every element of _this finite domain_." Not "holds in general". The domain must be named whenever the result is cited.
| *T-MACH* | Discharged *by machine proof* — a total, `--safe`-clean development checked by a prover, with no `believe_me`/`sorry`/`Admitted`/`postulate`. | "Holds for all inhabitants of the stated type." Says nothing about compiled Rust or Zig unless a refinement links them — and none exists here (see OPEN-1).
| *T-OPEN* | *Not discharged.* No proof, no exhaustive test, or the artefact exists but is checked by nothing. | Nothing. Silence is not affirmation.
|===

A fourth caution applies throughout: several artefacts *compile and are gated*
while proving nothing about this project. They are marked *EXEMPLAR*. A green
gate over an exemplar is evidence the prover ran, and is not domain coverage.

`tests/constitutional.rs` (C8–C13). The crate is `#![forbid(unsafe_code)]` with
zero external dependencies.

| C2 | Snark is a stable 49-cell counterfactual | the Snark pattern
| C3/C4 | Snark reaction yields only a causal reflected glider, and recovers | a 240-generation trace
| C5 | Rendering is observational and cannot change history | the stated render/step interface
| C6 | Rotated chart maps Life diagonals to BLACKGLIDER axes exactly | the four diagonal directions
| C7 | Replay material reconstructs the identical history | the traced run

| C9 | The exact chart is bijective onto the same parity sublattice | the chart's stated domain
| C10 | Graph surface and rigid attitude preserve distinct events | the enumerated event set
| C11 | All 16 glider heading/phase patterns are detected and translate correctly | *all 16* heading×phase patterns
| C12 | Causal radius bounds: a 9×9 world and a 15×15 dead-padded world agree cell-for-cell within the radius, so world size is causally irrelevant | *all 512* 3×3 seed masks × 4 generations

*What this tier does not give you.* Exhaustion over 4×4 says nothing about
5×5. The oracle agreement is agreement with a second implementation, not with a
specification. C1–C13 are strong evidence and they are not theorems over
unbounded worlds. Cite the domain or do not cite the result.

`src/lib.rs` defines *zero* unit tests; all 12 obligations live in
`tests/`. 613 LOC of source against 357 LOC of tests.

=== ABI/FFI boundary proofs (Idris2) — proved, but over a model

All five compile and are gated. Every one is *T-MACH over a model of a C ABI*,
not over the shipped Zig FFI. See OPEN-2 before citing any of them.

[cols="1,3,1,3", options="header"]
|===
| # | Proof | Status | File

| ABI-1 | Non-null pointer proofs (`SafePtr`, `So`-witness uniqueness, handle equality) | *T-MACH (model)* | `verification/proofs/idris2/ABI/Pointers.idr`
| ABI-2 | Struct size/alignment/padding; alignment stated as divisibility *with a `NonZero` conjunct* | *T-MACH (model)* | `verification/proofs/idris2/ABI/Layout.idr`
| ABI-3 | Per-platform pointer/int/`size_t` sizes with LTE bounds | *T-MACH (model)* | `verification/proofs/idris2/ABI/Platform.idr`
| ABI-4 | FFI function return type proofs | *T-MACH (model)* | `verification/proofs/idris2/ABI/Foreign.idr`
| ABI-5 | C ABI compliance record over Layout + Platform | *T-MACH (model)* | `verification/proofs/idris2/ABI/Compliance.idr`
|===

Two defects were introduced while repairing these and caught by adversarial
review; both are fixed, and both are recorded here because they are the kind of
regression a green gate cannot see:

* ABI-2 was briefly restated as divisibility *without* a `NonZero` conjunct,
  which is strictly weaker than the `mod` phrasing it replaced: at alignment 0
  a complete `CABICompliant` certificate could be built for a size-0,
  alignment-0 struct that cannot exist in C. The conjunct is back; the attack
  is now rejected while legal layouts still prove.
* De-erasing proof witnesses (quantity 0 → unrestricted) silently cost the
  newtype-transparent representation — measured with `--dumpcases`, `SafePtr`
  became a two-field heap object per pointer. Reverted; the correct repair was
  one character on the *accessor* (`0 safePtrNeverNull`).

== Tier 3 — NOT discharged (T-OPEN)

[[OPEN-1]]
=== OPEN-1 — No refinement connects the Idris2 model to the Rust kernel

*Nothing proves that the proofs and the implementation agree.* They are verified
separately: `Constitution.idr` proves the constitutional equations of a model,
`tests/foundation.rs` and `tests/constitutional.rs` exhaust a finite domain of
the implementation, and no machine-checked artefact relates the two. If the
Rust `Life::step` and the Idris2 `nextCell` diverged, both tiers above would
stay green. Until a refinement exists, "the Conway physics is proven" is an
overclaim; the defensible statement is "the equations are proven of a model and
the implementation is exhaustively tested on stated finite domains".

[[OPEN-2]]
=== OPEN-2 — The ABI proofs have no inhabitants from the shipped FFI

`grep -rn 'CABICompliant\|StructLayout' --include='*.zig' --include='*.rs' .`
returns *nothing*. No Rust or Zig struct is ever presented to the compliance
certificate; the only inhabitant is a fieldless empty struct. ABI-1…ABI-5 are
therefore proofs about a *model* of a C ABI, not about the seam that ships.
Smallest useful step: generate `StructLayout` values from the actual FFI types
so the certificate has real inhabitants and the Zig side is what is certified.

The Zig side itself is now tested — `zig build test --summary all` → 11/11
tests, 5/5 steps — but tested is not proved, and none of those tests consults
the Idris2 layout model.

[[OPEN-3]]
=== OPEN-3 — The TLA+ obligation is checked by nothing, and models the wrong system

`verification/proofs/tlaplus/StateMachine.tla` exists. It is:

* *Uninstantiated.* Its own header says "TLA+ Specification Template: State
  Machine / Replace with your project's distributed protocol". Its states are
  `idle`, `scanning`, `routing`, `dispatching`, `done`, `failed` — a generic
  request pipeline, irrelevant to a Conway spacetime.
* *Unwired.* `scripts/check-proofs.sh` accepts only `idris2|lean4|agda|coq`;
  there is no `tlaplus` mode. The only thing in the repo that touches the
  directory is `build/just/proofs.just:52`, which runs `find … | wc -l` — it
  *counts files*, it does not check them.
* *Uncheckable here.* No TLA+/TLC toolchain is installed.

No obligation of this project is discharged by it, and no obligation of this
project currently needs it (the kernel is single-threaded and there is no
distributed protocol). Resolve by instantiating it against something real *and*
adding a gated TLC mode, or by deleting the file. An unchecked uninstantiated
template inside `verification/proofs/` is the exact shape that gets miscounted
as coverage.

[[OPEN-4]]
=== OPEN-4 — Coq, Agda and Lean carry no domain obligation

See TP-2/TP-3/TP-4 above. Three gated, green provers; zero project coverage
between them. Either assign each a real obligation from this file, or move them
to an explicitly-labelled examples root that no readiness claim may cite.

[[OPEN-5]]
=== OPEN-5 — Renderer and mission semantics: no code, therefore no proof

The presentation/renderer layer and the mission semantics *do not exist yet*
(`STATE.a2ml`: 25% complete). Every obligation below is open by construction,
not by neglect:

[cols="1,4,1,2", options="header"]
|===
| # | Obligation | Category | Prover (intended)

| DOM-5 | Renderer is observationally inert on the *implemented* renderer — C5/C13 currently constrain an interface, not a renderer that draws | DOM/INV | Idris2 + exhaustive Rust
| DOM-6 | Geometric flight presentation preserves canonical causality under coordinate curvature (the repo's IS-NOT explicitly denies the converse) | DOM | Idris2
| DOM-7 | Mission semantics: a frozen mission specification, then replay-certificate soundness | DOM/ALG | Idris2 + golden-file tests
| DOM-8 | Mission replay determinism across runs and machines | ALG | exhaustive + certificate
|===

`PROOF-ROADMAP.md` names the frozen mission specification as the next real
step; DOM-6…DOM-8 are blocked on it, and DOM-5 on the renderer existing.

== Dangerous Patterns (BANNED)

The following MUST NOT appear anywhere in proof files:

[cols="2,2,3", options="header"]
|===
| Pattern | Language | Meaning

| `believe_me` | Idris2 | Unsafe cast / trust-me
| `assert_total` | Idris2 | Skip totality check
| `postulate` | Idris2/Agda | Unproven axiom
| `sorry` | Lean4 | Incomplete proof
| `Admitted` | Coq | Incomplete proof
| `unsafeCoerce` | Haskell | Unsafe type cast
| `Obj.magic` | OCaml/ReScript | Unsafe type cast
| `unsafe` (unaudited) | Rust | Unsafe block without safety comment
|===

Enforced by `scripts/scan-dangerous.sh`, invoked from `tests/aspect_tests.sh`,
which is a job in `.github/workflows/proof-gate.yml`. Measured 2026-08-07:
PASS=2 FAIL=0 WARN=0. The previous Idris2 arm of this scan grepped `src/abi/`,
a path that has never existed in this repo, and so could only ever pass; it has
been replaced. The Rust crate is `#![forbid(unsafe_code)]`, which makes the
last row a compiler error rather than a grep.

== Where the gates run

[source,bash]
----
just test                     # cargo + zig + abi.ipkg + all four check-proofs modes
bash scripts/check-proofs.sh idris2   # and coq | agda | lean4 — MANIFEST-driven
idris2 --typecheck abi.ipkg           # the SHIPPED seam
----

`.github/workflows/proof-gate.yml` (new, 2026-08-07) runs the aspect tests, the
Zig FFI tests, `abi.ipkg`, and one job per prover, each installing its own
toolchain. Before it existed, `grep -rn 'check-proofs\|proof-check\|just test'`
over `.github/workflows/` returned *no hits* — every proof was enforced on one
laptop and nowhere else.

Known gate debt, recorded not hidden: the CI jobs install provers from distro
packages and elan, whose versions may drift from the Idris2 0.7.0 / coqc 8.20.1
/ Agda 2.6.4.3 / Lean 4.32.2 the MANIFESTs were ground-truthed against, and
`mise.toml` pins rust, just and zig but *not* the four provers that `just test`
now treats as fatal-if-absent. A version-induced failure is a real signal about
proof portability; do not paper over it with a skip.

== Prover Selection Guide

[cols="2,2,3", options="header"]
|===
| Use Case | Recommended Prover | Why

| ABI/FFI boundaries | *Idris2* | Dependent types model layouts precisely
| Type system proofs | *Coq* or *Lean4* | Mature proof assistants for metatheory
| Algebraic properties | *Lean4* | Good mathlib support
| Inductive/coinductive | *Agda* | Native support for (co)induction
| Distributed systems | *TLA+* | Model checking for protocols
| Numerical properties | *Isabelle* | Strong real analysis library
|===
