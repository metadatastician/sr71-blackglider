== What this is, and how it works

SR-71 BlackGlider is an exact B3/S23 Conway kernel written in Rust. Its
flight presentation is meant to observe the Life history and never author
it. Around the kernel sit:

* a constitutional test suite (C1–C13);
* an Idris2 constitutional companion;
* an Idris2 ABI seam and a Zig FFI seam;
* a gated proof sweep across four provers.

This file reports what the repo's own checks produced at one commit. It
replaces the 2026-08-07 affirmation. Every claim in that file that could be
re-run was re-run, and the ones that no longer hold are listed under
<<outstanding>>.

[[nuance]]
=== The honest nuance you must not lose

* *C1–C13 is 13 obligations in 12 tests.* C3 and C4 share one test
  function (`c3_c4_snark_reaction_...`). The old file's "12 constitutional
  obligations C1–C13" counted tests, not obligations.
* *Exhaustion is over finite domains.* 512 local configurations and 65,536
  4×4 worlds are complete for those domains only. Behaviour on larger worlds
  rests on the 240-generation Snark trace (C2–C4) and on C12's causal-radius
  test, not on a proof (DEBT T-1).
* *The Coq, Agda and Lean modules prove nothing about this project.* They are
  RSR template exemplars. Their PASS is a statement about the gate (DEBT
  P-1).
* *No refinement connects the Idris2 model to the Rust kernel.* Both sides
  pass, and nothing proves they agree (DEBT P-2).
* *The Zig FFI is an unconsumed seam.* It builds and tests, but the Rust
  kernel does not call it (DEBT C-3).
* *The Lean gate ran on Lean 4.15.0.* `check-proofs.sh` printed a Lean 4.34.1
  banner from the repo root, but it compiles from inside
  `verification/proofs/lean4`, where elan selects the pinned `v4.15.0`.

== Reproduce it yourself

Run these from a clean checkout of the anchor commit, with the toolchain
above on `PATH` and a valid Agda `libraries` file.

[source,bash]
----
cargo build --all-targets --locked     # exit 0, 0 warnings
cargo test --all-targets --locked      # 6 + 6 passed, 0 failed
cargo fmt --check                      # exit 0
cargo clippy --all-targets -- -D warnings   # exit 0
(cd src/interface/ffi && zig build test --summary all)  # 11/11 tests
idris2 --typecheck abi.ipkg            # exit 0
for p in idris2 coq agda lean4; do bash scripts/check-proofs.sh "$p"; done
                                       # 7/7, 1/1, 1/1, 1/1 PASS
bash scripts/scan-dangerous.sh         # exit 0
just test && just quality              # exit 0
bash tests/aspect_tests.sh             # PASS=2 FAIL=0
bash tests/e2e.sh                      # PASS=6 FAIL=0
bash scripts/validate-template.sh      # 0 errors, 6 warnings
reuse lint                             # exit 1
----
